  This is the first post on this site. I think it wouldn't be appropriate to write about anything other than the page itself, so here we are.                           
                                         
  I'd be lying if I claimed that anything up to this point, excluding this first post :), is human-made. After all, as you can probably already tell, most of my current
   work involves in some way building on/with AI (usually `claude code`).
                                                                                                                                                                        
  A couple of months ago, I decided it's time for me to finally take part in the AI world and start working on my own personal projects and ideas, outside the scope of 
  uni coursework or work-related projects. It all began with finally switching from ChatGPT to Claude Max *(all paid up from work!)*.
                                                                                                                                                                        
  I was immediately both amazed and scared (still am), I could suddenly work on more than 10 projects simultaneously. I would see raw ideas take shape and turn into a  
  working demo in just a few hours; I had literally 10 terminal windows open at the same time, all running claude in different directories. **I had become a full-time 
  project manager.**                                                                                                                                                    
                                         
  Around a month into this new workflow, my output had exploded. Codebases started growing, were more ambitious and increased in numbers. Every problem encountered     
  would generate a new idea that would in turn give birth to a completely new project of its own. An example of this is [Alfred](/projects/alfred), which originally was
   designed to be an admin dashboard for [Brainifai](/projects/brainifai).                                                                                              
                                         
  This, however, inevitably ran into some issues. Despite the sheer volume of the total work output, I was nowhere near finishing or deploying any one of them. After a 
  while, every project would end up looking like an unorganised mess of code, old plan files and ideas that were impossible to navigate. **I realised I had nothing to 
  show from all these months of continuous work.**                                                                                                                      
                                         
  This site is a step into trying to deploy something complete as well as having a way to showcase not only finished products but also ideas, works-in-progress. It is  
  also a tool that will allow me to write down some thoughts or problems I will be encountering in this journey of exploring AI.
                                                                                                                                                                        
  I'm not sure how long it has been since I last wrote something like this without making use of an LLM and to be honest it does feel kind of refreshing. This site was 
  built using AI. Its content will be written by me.
                                                                                                                                                                        
  *(Until I have enough training data for a LoRA xD).*
